# UI Styling Skill

A comprehensive skill combining shadcn/ui, Radix UI, and Tailwind CSS for building modern, accessible user interfaces.

## Core Stack

**shadcn/ui + Radix UI**: Pre-built, accessible components distributed via copy-paste. TypeScript-first with full type safety. Composable primitives for complex UIs.

**Tailwind CSS**: Utility-first styling framework with zero runtime overhead through build-time processing and automatic dead code elimination.

**Canvas-Based Design**: A visual design layer emphasizing minimal text and maximum visual impact with sophisticated, systematic compositions.

## Primary Use Cases

Building React-based applications, implementing accessible components (forms, dialogs, tables, navigation), styling with utilities, creating responsive layouts, establishing dark mode, and designing consistent design systems.

## Quick Implementation

Run `npx shadcn@latest init` to configure both shadcn/ui and Tailwind, then rapidly add components and apply styling.

**Performance best practice:** Leverage automatic CSS purging, avoid dynamic class names.
