# Slides Skill (ckm:slides)

A tool for crafting strategic HTML presentations with Chart.js data visualization, design tokens, responsive layouts, and copywriting best practices.

## Key Capabilities

- Marketing presentations and pitch decks
- Data-driven slides with Chart.js
- Strategic slide design with layout patterns

## How It Works

1. Extract the subcommand (first word of arguments)
2. Retrieve the corresponding reference file
3. Execute using remaining parameters

## Primary Resources

- **Layout Patterns** — Structural design approaches
- **HTML Template** — Markup foundation
- **Copywriting Formulas** — Content optimization methods
- **Slide Strategies** — Contextual presentation approaches

## Usage

The `create` subcommand generates presentation slides, accepting a topic and slide count as arguments (e.g., `create "marketing strategy" 10`).
